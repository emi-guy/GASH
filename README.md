General Atomics tool for Simulating HIRF (GASH)

GASH is a project that seeks to simulate Low-Level Swept Current (LLSC) and Low-Level Swept Frequency (LLSF) on GA-ASI aircraft. This tool is desirable as it allows the EMI team to gather a rough estimate of the outcomes of these tests, without going through the very expensive and time-consuming process of actually running the tests.
